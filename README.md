# Toolmancer

Toolmancer provides free Windows utilities including network tools, media tools, and system utilities.

Download tools here:
https://toolmancer.com

## Available tools

### Network Tools
- IP Scanner
- Ping Tool
- DNS Benchmark
- Port Scanner
- Internet Speed Test Tool
- Wake on LAN Tool

### Media Tools
- Metadata Scanner
- Missing Episode Scanner
- Track Stream Scanner

### Windows Tools
- Port Analyzer
- Registry Compare Tool
- Registry Search Tool

Browse all apps:
https://toolmancer.com/apps/browseallapps
