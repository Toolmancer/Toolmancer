## Available Tools

### Network Tools
- IP Scanner
- Ping Tool
- DNS Benchmark
- Port Scanner
- Internet Speed Test Tool
- Wake on LAN Tool

### Media Tools
- Metadata Scanner
- Missing Episode Scanner
- Track Stream Scanner

### Windows Tools
- Port Analyzer
- Registry Compare Tool
- Registry Search Tool

## About

Toolmancer provides lightweight utilities designed to solve common problems on Windows systems.  
All tools are free to download with no advertisements.
